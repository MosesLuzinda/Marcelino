# Marcelino Platform — Demo Walkthrough

## 1. Public Website
- **Home:** Hero, stats, features, testimonials
- **Navigation:** All marketing pages responsive
- **AI Chatbot:** Bottom-right assistant for FAQs

## 2. Authentication
- Login at `/auth/login`
- Role-based redirect to correct portal

## 3. Student Portal
- Dashboard with grades, assignments, attendance
- Schedule, exams, messaging, profile

## 4. Teacher Portal
- Class management, attendance marking
- Grade upload, assignment creation, analytics
- Live class (Meet/Zoom links)

## 5. Parent Portal
- Child performance & attendance
- **Fee payment:** Flutterwave, MTN MoMo, Airtel, Stripe, PayPal

## 6. Admin Portal
- School-wide dashboard with charts
- Manage students, teachers, classes, finance
- Library, hostel, transport, inventory modules

## 7. Mobile Responsiveness
- Bottom navigation on portals
- Collapsible sidebar, touch-friendly UI
